# Compressed Population Scale Network NL - Simplified

This repository contains scripts to process and simplify multilayer population-scale social network data by grouping detailed layer types into broader social context categories.

## Overview

This repository is part of the **PLANET-NL** project pipeline for processing population-scale social network data from CBS (Statistics Netherlands).

This project transforms detailed multilayer networks (generated by the [compressed_population_scale_network_nl](https://github.com/planet-nl/compressed_population_scale_network_nl) repository) into simplified 5-layer undirected networks. The simplification process:

- **Collapses** detailed layer types into 5 primary social contexts
- **Converts** directed networks into undirected by symmetrizing all ties
- **Filters out** specific relationship types (see [Data Processing](#data-processing) below)
- **Preserves** node attributes from the original networks

## Network Layers

The simplified network consists of 5 layers representing distinct social contexts:

| Layer ID | Label      | Binary Encoding | Description                    |
|----------|------------|-----------------|--------------------------------|
| 0        | household  | 1               | Co-residence relationships     |
| 1        | school     | 2               | Educational connections        |
| 2        | neighbor   | 4               | Neighborhood proximity         |
| 3        | work       | 8               | Workplace relationships        |
| 4        | family     | 16              | Kinship ties                   |

Each layer uses a unique binary encoding that allows for efficient representation of multilayer memberships.

## Data Processing

### Excluded Relationships

The simplification process **excludes** the following relationship types from the original detailed networks:

1. **Sampled neighbor links** (CBS layer 102) - Random neighborhood connections
2. **By-partnership family members** (CBS layers 320, 321, 322) - By-partnership non-reciprocated kin relationships
3. **Institutional household members** (CBS layer 402) - Only people living at the same address are retained

### Network Symmetrization

All directed edges in the original network are converted to undirected edges by:
1. Filtering the adjacency matrix by layer type
2. Creating the transpose of the filtered matrix
3. Combining both matrices to create symmetric (undirected) connections

## Installation

Install required Python packages:

```bash
pip install pandas scipy mlnlib==0.2.39
```

Or if a `requirements.txt` is provided:

```bash
pip install -r requirements.txt
```

**Required packages:**
- `pandas` - Data manipulation
- `scipy` - Sparse matrix operations
- `mlnlib==0.2.39` - MultiLayerNetwork library for loading and saving MLN format

## Usage

### Single Year Processing

Process a single year's network data:

```bash
python grouped_networks.py <input_folder> <output_folder> <year>
```

**Arguments:**
- `input_folder`: Path to the raw network data directory (source data from the output of compressed_population_scale_network_nl)
- `output_folder`: Path where simplified networks will be saved
- `year`: The year to process (e.g., 2009)

**Example:**
```bash
python grouped_networks.py H:\\ODISSEI_portal_A H:\\ODISSEI_portal_B 2009
```

### Batch Processing (Longitudinal Data)

Process multiple years of network data using the provided shell script:

```bash
bash 00_run_all.sh
```

**Configuration:**
Edit the following variables in `00_run_all.sh`:
- `input_folder`: Source data directory
- `output_folder`: Output directory
- `start_year`: First year to process (default: 2009)
- `end_year`: Last year to process (default: 2023)

The script will:
- Process all years sequentially from `start_year` to `end_year`
- Generate timestamped log files for standard output and errors
- Save simplified networks to the output folder

## Output Format

The processed networks are saved in MultiLayerNetwork (MLN) format with:
- **Undirected edges** across 5 social context layers
- **Binary layer encodings** as specified in `layers.csv`
- **Preserved node attributes** from the original network
- **Compressed sparse matrix** representation for efficient storage

## Technical Details

### Layer Grouping

The script reads a detailed layer table from the source data and groups layers based on the `group` column. Binary encodings are summed for each group to create the final layer representation.

### Performance

- Uses sparse matrix operations (`scipy.sparse.csr_matrix`) for memory efficiency
- Implements garbage collection to manage memory during processing
- Processes each layer sequentially with progress logging
- Typical processing time varies based on network size and available system resources

## Input Data Format

This script expects input data in **MLN (MultiLayerNetwork) format** as produced by the upstream pipeline:

- `{input_folder}/{year}/` directory structure, with each folder containing:
  - `nodes.csv.gz` - Node attribute file
  - `layers.csv` - Layer definition file
  - `edges.npz` - Binary encoded sparse adjacency matrix with directed edges


The script uses `use_polars=True` for efficient data loading when available.

## Environment Notes

- The example paths in `00_run_all.sh` use Windows-style paths (e.g., `H:\\ODISSEI_portal_A`) as the original development was done in the CBS Remote Access (RA) environment
- The code works on Linux/Unix systems; adjust paths as needed for your environment
- Ensure sufficient disk space for temporary sparse matrices during processing

## Troubleshooting

### Common Issues

**Missing input files:**
- Verify that the input folder contains the expected year directory with MLN-formatted data
- Check that `layers.csv` exists in the source data with a `group` column

**Memory errors:**
- Processing population-scale networks requires significant RAM
- Ensure adequate swap space is available
- Consider processing years individually rather than in batch

**Path issues:**
- On Linux/Unix, replace Windows backslashes (`\\`) with forward slashes (`/`) in paths
- Use absolute paths when possible to avoid ambiguity

**Layer encoding errors:**
- Ensure the output folder contains `src/layers.csv` with the correct binary encodings
- This file should match the format in the repository's `layers.csv`
